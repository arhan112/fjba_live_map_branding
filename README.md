# FjBa LIVE MAP BRANDING — AURORA VORTEX

**A visual branding experience for QGIS**

## Overview

FjBa LIVE MAP BRANDING — AURORA VORTEX is a QGIS plugin designed to enhance the visual presentation of the QGIS workspace with an animated branding overlay and clock.

## Features

- Animated Aurora Vortex clock.
- Animated FjBa title with metallic visual effects.
- Four visual themes.
- Infinity-inspired particle animations.
- Movable floating branding panel.
- Adjustable panel position, opacity and width.
- Configurable clock visibility.

## Compatibility

- Target QGIS version: 3.28.4
- Python: 3.9
- Interface: PyQt5

Compatibility with other QGIS versions and operating systems requires testing.

## Installation

1. Open QGIS.
2. Select Plugins → Manage and Install Plugins.
3. Search for FjBa LIVE MAP BRANDING.
4. Select Install Plugin.

## Usage

Activate the plugin from the QGIS Plugins menu or toolbar. Open its settings to customise the appearance and position of the branding overlay.
